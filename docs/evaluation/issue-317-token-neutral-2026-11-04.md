# Issue #317 token-neutral evaluation

Date: 2026-11-04 (Asia/Shanghai)

## Decision

No new optimization is accepted by this evaluation. The constraint remains strict:
captain/member prompt, tool, schema, and call footprints must not increase in any
dimension. The exact before/after comparison required to prove neutrality is not
available, so the result is **not proven token-neutral**.

## Scope and next evidence

The existing `toolSurface: core` mode is already implemented; this run does not
establish a newly proposed optimization. Prompt bytes and call counts were not
measured, so the full #317 neutrality claim remains unproven. Do not change the
default surface or remove tools under #317 based on this evidence. Any candidate
must capture exact captain and member ledgers from the same host/profile before
and after, including prompt bytes, tool count, serialized schema bytes, and call
count. Reject it if any dimension increases.
