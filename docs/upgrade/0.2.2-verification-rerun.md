### 3.3 变异验证（证明断言有牙）

在 `/tmp/t4-mut`（rsync 副本 + `node_modules` 软链）上改 `lib/scheduler.js` 的 reconcile 过滤：

| 变异 | 结果 |
| --- | --- |
| 过滤整体替换为 `.filter(message => false)` | 退出码 1，唯一红 = **A4**：`unread=["Member \"worker\" hit an unrecoverable tur…"]` → 重试成功后提醒仍在（正是被修的缺陷） |
