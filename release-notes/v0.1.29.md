# v0.1.29 — Harness 0.2.1-rc.5 recommended baseline

AgentTeams `0.1.29` promotes DeepSeek Harness `0.2.1-rc.5` (npm `latest`) to the recommended host and exact development baseline. rc.2, rc.3, rc.4 and all previously tested hosts remain supported.

- Move every direct DSH development dependency and workspace override to exact `0.2.1-rc.5`; regenerate the lockfile and the complete exact host cohort.
- Keep the published install policy unchanged: `engines.dsh` remains `>=0.1.2-alpha.2` and every DSH peer remains `*`, so later hosts stay installable through the official plugin manager and npm.
- No AgentTeams runtime/API migration is required. The rc.5 client changes to composer draft replacement, View pinning, and reasoning raw/display fields do not alter the slots or session-navigation capabilities used by AgentTeams.
- Keep all older host targets in the compatibility matrix; rc.2 becomes a supported preview host rather than the recommended baseline.

## Validation

The stable candidate is built against the exact rc.5 development cohort and verified with `pnpm verify`, all real rc.5 runtime scenarios (entry, lifecycle, fallback, failure, idle wakeup, Web approval, protocol compatibility, stability, plugin-manager install), and exact-artifact desktop-profile installation. A fresh 0.1.29 UI smoke test remains pending because the running desktop host was still on 0.1.28 and the macOS session was locked; the earlier 0.1.28 UI smoke test covered the same AgentTeams surfaces. The plugin still does not claim real-provider model behavior or fix third-party plugin incompatibilities such as `@deepseek-ai/dsh-subagent-codex@0.2.1-rc.3`.
